# NFTStackPlus

NFTStackPlus: A real-time, distributed data pipeline manager for blockchain-integrated, auto-scaling NFT market ecosystem systems.

NFTStackPlus is aimed at developers who need a straightforward, dependable solution.

## Installation

1. Clone the repository: `git clone https://github.com/harutosati/NFTStackPlus.git`
2. `cd NFTStackPlus`
3. Install in editable mode: `pip install -e .`

## Configuration

NFTStackPlus is configured through environment variables (see `.env.example`). Key options:
- **APP_ENV**: `development` or `production`.
- **PORT**: Port the server listens on.
- **LOG_LEVEL**: `debug`, `info`, or `error`.
